# Extend Weather Years – README

## Overview

**Type:** Pre
**Platform:** PLEXOS
**Version:** 1.0
**Last Updated:** March 2026
**Author:** Energy Exemplar

### Purpose

Extends weather-year modeling inputs in a PLEXOS study by registering sampled CSVs generated by the weather-sampling script into the model database, creating and linking Variable and Scenario relationships, updating stochastic sample count, and safely exporting the updated model to `project.xml`.

### Key Features

1. Create Data File objects (one per sampled CSV)
2. Create Variable objects (with `_CY` suffix)
3. Link Variables to model objects and group under a scenario
4. Update stochastic sample count to match number of years
5. Link Scenario to the Model object
6. Link Stochastic object under the Model parent
7. Safely export the updated model DB to `project.xml` with backup/restore behavior

### Related Scripts

> Scripts commonly chained with this one.

- **Before this script:** `../WeatherSample/sample_weather_years.py` (generates sampled weather CSV files into `ExoSampled`, which this script registers into the model)
- **After this script:** PLEXOS simulation execution task

## Arguments

| Argument | Required | Default | Description |
|---|---|---|---|
| `--model-path PATH` | Yes* | — | Path to model `.db` file. If omitted, uses `simulation_path/reference.db` then `sqlite_input_path`. |
| `--study-id` | Yes*** | — | PLEXOS study ID for final DB to `project.xml` conversion. Not required for `--dry-run`. If omitted, falls back to `study_id` environment variable. |
| `--sampled-dir` | No | `ExoSampled` | Folder containing sampled CSV files from Step 1. |
| `--dry-run` | No | off | Preview operations without writing to the model or regenerating `project.xml`. |
| `--use-full-filename` | No | off | Use full filename (with extension) as object name. |
| `--object-name-prefix` | No | — | Prefix added to created object names. |
| `--data-file-category` | No | — | Category assigned when creating Data File objects. |
| `--create-variables` | No | off | Create Variable objects for sampled files. |
| `--variable-name-suffix` | No | `_CY` | Suffix appended to Variable names. |
| `--variable-category` | No | — | Category assigned when creating Variable objects. |
| `--variable-band-attribute-lang-id` | No | auto | Explicit Variable band attribute lang ID. |
| `--require-variable-band-attribute` | No | off | Fail if no Variable band attribute can be resolved. |
| `--start-year` | No | `1982` | Start climate year used for band/sample count. |
| `--end-year` | No | `2016` | End climate year used for band/sample count. |
| `--link-variables` | No | off | Link Variables to target objects and Scenario. |
| `--target-class-name` | Yes** | — | Parent object class name for linking (for example `Generator`). |
| `--scenario-name` | No | `Weather_Variables_CY` | Scenario name used for Variable grouping. |
| `--scenario-category` | No | — | Category assigned when creating Scenario object. |
| `--scenario-read-order` | No | `50001` | Read Order attribute value for the Scenario. |
| `--scenario-class-lang-id` | No | auto | Explicit Scenario class lang ID. |
| `--adjust-stochastic` | No | off | Update stochastic sample count. |
| `--stochastic-object-name` | No | `Weather_Stochastic` | Stochastic object name to update/create. |
| `--stochastic-parent-name` | No | `Model` | Parent Model object name for memberships. |
| `--stochastic-parent-category` | No | — | Category assigned when creating parent Model object. |
| `--stochastic-parent-class-lang-id` | No | auto | Explicit parent Model class lang ID. |
| `--sample-count-override` | No | — | Explicit sample count override. |
| `--stochastic-class-lang-id` | No | auto | Explicit Stochastic class lang ID. |
| `--stochastic-sample-attribute-lang-id` | No | auto | Explicit stochastic sample-count attribute lang ID. |

\* Not required when model path is available via environment fallback.  
\*\* Required when `--link-variables` is used.  
\*\*\* Required via argument or environment variable when not using `--dry-run`.

## Environment Variables Used

| Variable | Description |
|---|---|
| `simulation_path` | Used to resolve fallback model path (`simulation_path/reference.db`) and as base path for `--sampled-dir`. |
| `sqlite_input_path` | Secondary fallback model path when `--model-path` is not provided and `simulation_path/reference.db` is unavailable. |
| `study_id` | Fallback study ID used when `--study-id` is not provided and DB-to-XML export is performed. |
| `cloud_cli_path` | Cloud CLI path used by CloudSDK when DB-to-XML conversion is performed. |

## Expected Behaviour

### Success

1. Resolves model path from `--model-path`, then fallback env paths.
2. Validates sampled directory and discovers sampled CSV files.
3. Creates or updates Data File objects and Filename property values.
4. Optionally creates Variable objects and sets Variable attributes/properties.
5. Optionally links Variables to target objects and Scenario.
6. Optionally updates stochastic sample count.
7. When not using `--dry-run`, resolves study ID from `--study-id` or `study_id`/`STUDY_ID` env vars.
8. When not using `--dry-run`, safely exports updated DB to `project.xml` with backup/restore protection.
9. Exits with code `0`.

### Failure Conditions

| Condition | Exit Code | Recovery |
|---|---|---|
| Model path cannot be resolved | 1 | Provide `--model-path` or set `simulation_path`/`sqlite_input_path` |
| Model file not found | 1 | Verify `.db` path exists |
| XML model input provided | 1 | Provide `.db` model input |
| Sampled directory missing/empty | 1 | Generate CSVs using `sample_weather_years.py` first |
| `--target-class-name` missing while using `--link-variables` | 1 | Provide target class name (for example `Generator`) |
| Study ID not provided in arg or env | 1 | Provide `--study-id` or set `study_id`/`STUDY_ID` when not using `--dry-run` |
| DB to XML export failure | 1 | Verify study ID and Cloud SDK/CLI setup |
